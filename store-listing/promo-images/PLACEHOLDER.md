# Promo images — placeholder folder

Drop your promotional tile image files directly in this folder. Suggested filenames:

```
promo-images/
├── small-tile-440x280.png     (required for a public listing)
├── marquee-1400x560.png       (optional, only used if Google features the extension)
```

## Chrome Web Store requirements

| Asset              | Size        | Required?                    | Notes                                                                         |
| ------------------ | ----------- | ---------------------------- | ----------------------------------------------------------------------------- |
| Small promo tile   | 440×280 px  | **Yes**, for public listings | Shown in search results and category listings.                                |
| Marquee promo tile | 1400×560 px | No                           | Only used if Google chooses to feature the extension; safe to skip initially. |

- **Format:** PNG or 24-bit JPG, no alpha transparency.
- **Design tips:** include the extension name/logo and a short value-prop phrase (e.g. "Print any section — clean & clutter-free"). Avoid dense text since the tile is shown small.

Once you add the real image file(s) here, delete this placeholder note.
