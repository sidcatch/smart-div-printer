## Detailed description (max 16,000 characters)

```
Smart Div Printer lets you visually select any part of a webpage and either print it in a clean, distraction-free layout or permanently hide it from all future prints on that site.

Perfect for saving articles, documentation, receipts, and reports to PDF while excluding ads, navigation bars, sidebars, comment sections, and other clutter.

HOW IT WORKS
1. Click the Smart Div Printer icon in your toolbar.
2. Choose "Select for PDF" (blue) to print, or "Select to Hide from Print" (red) to permanently exclude an element.
3. Hover over the page — the section under your cursor is highlighted in real time.
4. Click to select it. Use the on-screen controls (or Arrow Up / Arrow Down) to expand to a parent element or narrow to a child.
5. Press Enter or click the action button to print or hide it.

KEY FEATURES
• Dual mode operation — print immediately, or mark elements to hide from every future print on that site.
• Direct and Smart selection modes — pick the exact element you're hovering over, or let the extension find the best printable container automatically.
• Keyboard shortcuts — Arrow keys to expand/narrow the selection, Enter to confirm, Esc to cancel.
• Persistent hidden-element list, remembered per website, with an easy-to-use manager in the popup (enable, disable, or delete any entry).
• Clean print layout — expands hidden overflow/scrollable content, converts canvas elements to static images, and preserves form input values and checkbox states so what you see is what gets printed.
• Optional "preserve parent styling" mode that keeps a stripped-down copy of the page's ancestor elements so inherited CSS (theme colors, fonts, layout classes) still renders correctly in the print preview.
• Unsaved-changes warning before entering print preview, with a "don't show again" option you can re-enable anytime from the popup.

PRIVACY
Smart Div Printer does not collect, transmit, or sell any personal data. Everything — including the list of elements you've chosen to hide — is stored locally in your browser using chrome.storage.local and never leaves your device. See the full privacy policy for details.

KNOWN LIMITATIONS
• Cannot run on browser-internal pages (chrome://, edge://, the Chrome Web Store) due to browser security restrictions.
• Cross-origin iframes and cross-origin canvases cannot be captured due to standard web security rules.
• Selectors used to remember hidden elements may need to be re-created if a site's HTML structure changes significantly.

Open source under the MIT license.
```
